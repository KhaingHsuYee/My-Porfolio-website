Money Manager

A full-stack financial dashboard that replaces messy spreadsheets. Easily track daily cash flow, analyze spending habits, and export data using an intuitive, cloud-based platform.

The Aim

To provide individuals with a frictionless, visually engaging tool to take control of their personal finances. By automating data visualization and simplifying transaction entry, the platform aims to make budget auditing an effortless daily habit rather than a tedious monthly chore.

Main Features

Interactive Dashboard

Visualizes income and expenses in real-time using dynamic pie charts and trend lines to give an immediate overview of financial health.

Advanced Data Filtering

A robust search engine allowing users to quickly audit their transaction history by specifying date ranges, categories, or exact keywords.

One-Click Reporting

Instantly export transaction records into formatted Excel (.xlsx) files for local backup, or have the system email the report directly to your inbox.

Secure Authentication

Protects user data with JWT stateless sessions and professional HTML email verification links for seamless account onboarding.

Tech Stack

React (Vite) & Tailwind Recharts Java Spring Boot & Security MySQL (Local) / PostgreSQL (Prod) Cloudinary (Profile Image Storage) Netlify (UI) & Render (API) Brevo API (Emails)
