Inventory Management System

An automated, role-based enterprise application designed to track retail stock, handle supplier transactions, and generate automated low-stock email alerts.

Github Repo

The Objective

To replace manual inventory tracking in retail and warehouse environments. The system automates stock recording, significantly reduces manual human errors, and actively monitors stock levels to ensure timely reordering and improve overall operational efficiency.

Key Features

Role-Based Authority

Strict segregation of duties between Admins and Managers. Only Admins can modify core products and suppliers, while both roles can process transactions.

Automated Reorder Alerts

The backend runs daily inventory sweeps and automatically dispatches formatted email alerts to managers if any product drops below its specific reorder point.

Transaction Analytics

A comprehensive visual dashboard generating monthly reports, grouping transaction counts by type (Sales, Purchases, Returns) via interactive charts.

End-to-End Tracking

Complete lifecycle tracking from logging new supplier purchases to processing end-customer sales and handling inventory returns.
